# WPM

An arcade maze-chase game for Android. Clear every dot, dodge four drones (Blaze, Hex, Volt, Ember), and grab power cells to turn the tables.

- Swipe anywhere or use the on-screen pad to steer
- Ghost-house style pen, scatter/chase waves, tunnels, bonus items, extra life at 10,000
- Works fully offline; best score is saved on the phone

**Download:** open the [latest release](../../releases/latest) on your phone and install `WPM.apk`.

The game itself is `web/index.html` (also playable in any browser). Every push to `main` builds a new APK with GitHub Actions.
